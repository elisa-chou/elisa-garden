# 美式鬆餅
| 材料   | 份量   |
| ---- | ---- |
| 廢棄酵種 | 200g |
| 麵粉   | 100g |
| 糖    | 25g  |
| 蛋    | 1顆   |
| 鹽    | 少許   |
| 奶油   | 20g  |
| 牛奶   | 120g |
| 泡打粉  | 5g   |

做法：全部拌勻，直接平底鍋煎

補充：
- 麵糊可以放過夜，泡打粉先不加，下鍋前才加進去攪拌
  (建議麵糊不要放超過24小時)
- 奶油用小烤箱熱最快，可頌模式1分鐘
- 牛奶最後加，先把前面乾料拌勻會比較順 
  (因為麵團偏水，牛奶先下容易在水裡找不到結塊)

# 義式麵包棒 (Grissini)
| 材料                  | 份量   |
| ------------------- | ---- |
| 廢棄酵種                | 150g |
| 中筋或高筋麵粉             | 150g |
| 橄欖油                 | 27g  |
| 鹽                   | 4g   |
| 水（視麵糰狀態調整）          | 30ml |
| 表面裝飾（芝麻、迷迭香、粗鹽等，任選） | 8g   |

步驟：
1. **混合材料**：將酵種、麵粉、橄欖油、鹽混合，視麵糰狀態加入水，揉至成團不黏手即可，不需要揉到完全光滑。
2. **靜置鬆弛**：麵糰蓋起來靜置 30 分鐘。
3. **預熱烤箱**：烤箱預熱至 200°C。
4. **整形**：麵糰不需要擀，直接用手拉或用刮刀切成約 1cm 寬的長條，搓成細棒狀。排在鋪了烘焙紙的烤盤上，間距約 1cm。
5. **表面裝飾**：表面刷少許橄欖油，撒上喜歡的香料或鹽。
6. **烘烤**：送入烤箱烤 18–22 分鐘，直到表面金黃、摸起來硬實。冷卻後會更脆。


補充：
- 麵粉強烈建議用法國粉 (我是用T65)，會很像歐系餐廳吃到的風味。
  不建議用台灣麵粉，很沒味道。
- 酵種活性不重要，廢棄的酵種直接用就好。
- 想要更脆可以烤完關火，烤箱門開一條縫，讓麵包棒在裡面再乾燥 10 分鐘。
- 密封保存可放 3–5 天，軟掉的話吃之前補烤個3-5分鐘也可
- 橄欖油可以換成奶油，要融化後拌進去
- 整個食譜都可以等比例增減 (因為沒有蛋這種固定分量的東西)
