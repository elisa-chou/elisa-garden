# 食譜

此份食譜改編自Youtube影片：[天然酸種牛奶生吐司](https://www.youtube.com/watch?v=qclPHHhaBuM)

| 材料            | 份量   |
| ------------- | ---- |
| 牛奶            | 130g |
| 蜂蜜            | 30g  |
| 酸種            | 125g |
| 高筋麵粉          | 200g |
| 全麥麵粉 （暫時用T65） | 50g  |
| 海鹽            | 3g   |
| 奶油            | 25g  |

步驟：
1. **前一晚餵酸種：** 15酸種 : 80水 : 80麵粉 比例餵養酸種，室溫放至隔天早上。
2. **混合液體：** 將 130g 牛奶(120水＋4匙奶粉)、125g 活躍酸種與 30g 蜂蜜混合。
3. **加入乾料：** 加入 200g 高筋麵粉、50g 全麥麵粉與 3g 海鹽，混合成麵團。
4. **加入油脂：** 加入 25g 奶油，手揉至油脂完全融入。(專心大約2分鐘，看影片慢慢揉大概要5~10分鐘XD)
5. **第一次發酵：** 蓋好後於 25°C 室溫發酵約 3–4 小時，直到麵團膨脹至約 2 倍大。
6. **分割整形：** 將麵團分成兩等份，分別折疊收圓後靜置 20 分鐘。
7. **第一次捲整：** 將麵團輕輕擀成長方形，拍掉大氣泡後由上往下捲起。
8. **入模：** 將捲好的麵團放入塗油的吐司模中。==如果要用兩天做法，可以把麵團密封好丟冰箱==
   (吐司盒上蓋的奶油很容易被下面刮掉，蓋蓋子的時候自己多注意。)
9. **第二次發酵：** 發酵至麵團約達吐司模的 90% 滿，可以用烤箱發酵模式節省時間。
10. **預熱烤箱：** 提前 30 分鐘將烤箱預熱至 190°C。
11. **烘烤：** 以 190°C 烤 35 分鐘，至表面呈漂亮的金黃色。
12. **出爐：** 出爐後立即脫模並放在網架上冷卻。
